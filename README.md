# Bellabeat Capstone Project
**Google Data Analytics Professional Certificate — Case Study**

## Overview
An analysis of FitBit smart device usage data to uncover behavioral trends and provide data-driven marketing recommendations for Bellabeat, a women's health wearable company. The analysis follows the Google Data Analytics framework: Ask, Prepare, Process, Analyze, Share, and Act.

**Tools used:** R (tidyverse, ggplot2, dplyr, lubridate, janitor) · Google Sheets · Kaggle

**Dataset:** [FitBit Fitness Tracker Data](https://www.kaggle.com/datasets/arashnic/fitbit) — 35 users · 9 weeks · March–May 2016

## Key Findings
- **37% of users are sedentary** (<5,000 steps/day), the largest single user segment
- **Activity and sleep have a negative correlation** — very active users average only 6.6 hours of sleep, below the CDC's 7-hour minimum
- **Peak activity hours are 12PM–2PM and 5PM–7PM**, consistent with a standard 9-to-5 work schedule
- **87% average device wear rate**, but a notable user drop-off occurs between weeks 4 and 5
- **Only 37% of users track weight**, suggesting the feature lacks perceived value or friction in use

## Recommendation
Bellabeat's Leaf device is well-positioned to differentiate from fitness-first competitors by shifting its messaging toward holistic wellness — targeting the balance between activity, sleep, and recovery rather than raw performance metrics.
